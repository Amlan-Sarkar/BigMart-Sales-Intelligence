# BigMart Sales Intelligence & Prediction

Machine learning project that predicts **item-outlet sales** for BigMart retail stores and delivers the model through an interactive Streamlit app.

---

## Business Problem

BigMart operates multiple retail outlets selling thousands of products. Sales vary significantly across products and stores. The business needs to:

- Forecast expected sales for product–outlet combinations
- Identify which factors drive sales performance
- Support pricing, inventory, and outlet strategy decisions

**Goal:** Build an accurate, interpretable model and make it usable by non-technical stakeholders.

---

## Dataset

| Item | Details |
|------|---------|
| Source | [Kaggle – BigMart Sales Data](https://www.kaggle.com/brijbhushannanda1979/bigmart-sales-data) |
| Training records | 8,523 |
| Products | 1,559 unique items |
| Outlets | 10 stores |
| Target | `Item_Outlet_Sales` (₹) |

---

## Approach

1. **Data Cleaning** – Standardise categories, impute missing weights & outlet sizes, create outlet age
2. **EDA** – Sales distribution, product & outlet analysis, key business insights
3. **Feature Engineering** – MRP segments, outlet age groups, visibility flag, grouped item types
4. **Modelling** – Compare Linear Regression, Random Forest, Extra Trees, XGBoost, LightGBM
5. **Validation** – Hold-out split + GroupKFold (by product) to test generalisation to unseen items
6. **Explainability** – Feature importance + SHAP
7. **Deployment** – Streamlit app for interactive predictions

---

## Key Findings

- **Item MRP** is the strongest driver of sales
- **Outlet Type** is the second strongest driver
- Tree-based models clearly outperform a simple mean baseline
- The model is more reliable for known products; for brand-new products combine the prediction with baseline / expert judgment

*(Exact metrics are shown dynamically in the notebook and Streamlit app.)*

## How to Run

### 1. Notebook (training & analysis)

Open `notebook/Amlan Sarkar_BigMart Sales Intelligence Prediction.ipynb` in Jupyter / VS Code / Cursor and run all cells.

This will:

- Clean and explore the data
- Train and compare models
- Save all artifacts into the `models/` folder

### 2. Streamlit App (predictions)

```bash
streamlit run app.py
```

The app provides:

- **Make Prediction** – interactive sales forecast
- **Model Performance** – metrics for all models + feature importance
- **About** – project summary and assumptions
